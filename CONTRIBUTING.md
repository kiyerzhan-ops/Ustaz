# Contributing to Ustaz

Thank you for your interest in Ustaz.

## Before Contributing

Please keep changes focused on the educational platform and its user experience.

## Pull Requests

When opening a pull request:

1. Describe what you changed.
2. Explain why the change is needed.
3. Include screenshots for visible UI changes when useful.
4. Make sure the existing website behavior is not unintentionally broken.

## Blockchain Changes

Changes involving Solana should remain compatible with the project's current Devnet demonstration unless the project maintainers explicitly decide otherwise.

Never include private keys, seed phrases, passwords, or other secrets in commits.
