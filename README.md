# Ustaz

> Secure learning with blockchain-powered payments.

Ustaz is an educational platform that connects students with teachers and demonstrates a secure payment flow using **Solana Devnet** and **Phantom Wallet**.

## What Makes Ustaz Different

- 🎓 Learn from teachers through live lessons
- 🔐 Escrow-style payment concept
- ⛓️ Solana blockchain integration
- 👻 Phantom Wallet connection
- 🧪 Solana Devnet testing
- 🪙 Test-token transactions
- ⭐ Teacher ratings and reviews
- 🌐 English, Russian and Kazakh interfaces

## Blockchain & Wallet

**Network:** Solana Devnet  
**Wallet:** Phantom Wallet  
**Tokens:** Test tokens

The current blockchain functionality is a demonstration on **Solana Devnet**. It is not intended to process real-money payments.

## Payment Concept

The platform demonstrates an escrow-style flow:

1. Student selects a lesson.
2. Student connects a Phantom Wallet.
3. A test transaction is made on Solana Devnet.
4. The lesson takes place.
5. The student confirms the lesson.
6. The demonstration flow can release the teacher payout or show a refund path.
