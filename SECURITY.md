# Security Policy

## Scope

Ustaz is a prototype educational platform using Solana Devnet and test tokens.

## Reporting a Security Issue

If you discover a security issue in the project, please do not publish sensitive details in a public issue. Contact the project maintainers privately and provide a clear description of the issue and steps to reproduce it.

## Wallet Safety

Ustaz does not require users to provide private keys, seed phrases, or recovery phrases.

The current blockchain demonstration uses Solana Devnet and test tokens. Do not treat Devnet assets as real funds.
